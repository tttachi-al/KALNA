# Recursos gráficos

- `kallpa-mark.svg`: marca (tres peldaños que suben + punto dorado).
- `kallpa-logo.svg`: marca con el nombre, para documentos o presentaciones.

En la app, la marca se dibuja con el componente `src/components/ui/Logo.jsx` para que tome los colores del tema (claro/oscuro).
Los íconos provienen de `lucide-react` (una sola familia, trazo de 2 px).
